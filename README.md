# Best Face

> Find your best match. Single match. Rate all faces. Get your best mutual match. Just one match.

A minimalist, white-aesthetic single match discovery application built with **Next.js**, **Deno**, **InstantDB**, and the **Gale–Shapley Stable Marriage Algorithm**.

## Features

- **Pairwise Face Rating**: Compares faces in head-to-head pairs with Elo rating calculation.
- **Photo Upload & Profile**: Upload your photo and profile in Step 2 to enter the matching market.
- **Gale–Shapley Matching**: Nobel Prize–winning Deferred Acceptance algorithm to compute your single, mathematically stable mutual match with zero blocking pairs.
- **InstantDB Real-time Engine**: Instant real-time database schema for faces, comparisons, and match equilibrium.
- **Deno & Node Compatibility**: Fully runnable with `deno task dev` or `npm run dev`.

## Getting Started

### Using Deno:
```bash
deno task dev
# or build
deno task build
```

### Using Node / NPM:
```bash
npm run dev
# or build
npm run build
```

## Running Tests
```bash
deno task test
```
